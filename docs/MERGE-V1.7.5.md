## 三、按我们的代码风格落地（不是照抄他的写法）

他的写法是单文件里的全局函数 + 数组下标：

```js
['成长记录','成长数据 · 健康周报','i-chart','#4CA876',"go('health')"]
```

我们改成**数据表 + 命名字段 + 单一动作**：

```js
// src/data/home-entries.js
export const HOME_CARE_ENTRIES = [
  { id: 'health', label: '健康管理', desc: '成长数据 · 健康周报', icon: 'i-chart', color: '#4CA876', page: 'health' },
  { id: 'album', label: '成长记录', desc: '时光记忆 · 宠物照片', icon: 'i-img', color: '#3AB5C0', page: 'profile', tab: 'album' },
];
```

```js
// src/views/home.js
export function openHomeEntry(id) {
  const entry = HOME_CARE_ENTRIES.find((e) => e.id === id);
  if (!entry) return;
  if (entry.tab) ui.profTab = entry.tab;
  go(entry.page);
}
```

好处：模板里只有静态的 `app.openHomeEntry('health')`（能被 `dev/check.js` 校验），
文案与去向集中在 data 层（能被单测锁住），下标魔法消失。
